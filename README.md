# ⚽ Mascotes da Copa do Mundo FIFA (1966–2022)

Uma página simples e elegante para disponibilizar o download da apresentação **"Mascotes da Copa do Mundo FIFA (1966–2022)"**.

## 📖 Sobre o projeto

Este projeto foi criado para permitir que qualquer pessoa possa baixar facilmente a apresentação sobre os mascotes das Copas do Mundo FIFA, desde a criação do primeiro mascote em 1966 até o moderno La'eeb, da Copa do Mundo de 2022.

A página possui um design responsivo e funciona em computadores e celulares.

## ✨ Recursos

- 📥 Botão para baixar a apresentação;
- 🖥️ Compatível com Windows, Linux e macOS;
- 📱 Funciona em celulares Android e iPhone;
- 🎨 Interface moderna e fácil de usar;
- 🌐 Pronto para publicação no GitHub Pages.

## 📂 Estrutura do projeto

```
projeto/
├── index.html
├── README.md
└── Mascotes_da_Copa_do_Mundo_FIFA__1966-2022.pptx
```

## 🚀 Como usar

1. Faça o download ou clone este repositório.
2. Certifique-se de que o arquivo da apresentação esteja na mesma pasta do `index.html`.
3. Abra o arquivo `index.html` em seu navegador.

Ou publique no GitHub Pages para disponibilizar o download online.

## 🌍 Publicando no GitHub Pages

1. Envie os arquivos para um repositório no GitHub.
2. Acesse **Settings → Pages**.
3. Em **Deploy from a branch**, selecione:
   - Branch: `main`
   - Pasta: `/root`
4. Clique em **Save**.

Após alguns minutos, o site estará disponível em:

```
https://luquinha835.github.io/Lucca-e-Bruno/
```

- 🧊 Ciao (1990);
- 🐶 Striker (1994);
- 🐓 Footix (1998);
- 👽 Ato, Kaz e Nik (2002);
- 🦁⚽ Goleo VI e Pille (2006);
- 🐆 Zakumi (2010);
- 🦔 Fuleco (2014);
- 🐺 Zabivaka (2018);
- ☁️ La'eeb (2022).
